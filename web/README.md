# The Last Flight: browser chapter

Open `last-flight.html` in a modern browser. It is a self-contained HTML5 experience with no external libraries, paid assets, or network dependencies.

## Player journey
- Enter the airfield and board the aircraft.
- Start the engines and trigger takeoff.
- Steer the flight with climb, hold-course, and descend controls.
- Hear the impossible transmission and choose whether to divert.
- Experience the timeline collapse and wake in another life.
- Join the Collapsible Time early-player waitlist or share the invitation.

## Controls
All controls are large touch-friendly buttons and work with mouse/touch. The flight section advances gradually; holding course accelerates progress. Sound is optional and starts only after the player enables it.

## Rights and dependencies
All visuals are drawn in Canvas using original procedural shapes. No third-party game art, characters, maps, logos, or music are copied. No external packages or paid services are required.

## Status
This is a browser prototype committed on the isolated development branch. It has not yet been run through a real browser/device test or deployed to the public site. Test the complete touch journey, mobile layout, audio behavior, share action, and waitlist link before publishing.
